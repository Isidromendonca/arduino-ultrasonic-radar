# arduino-ultrasonic-radar
Learning project: joystick-controlled servo with ultrasonic distance detection, LEDs and buzzer.

## Descripción

Proyecto personal realizado como parte de mi aprendizaje de electrónica y programación de microcontroladores. Soy estudiante de 2do año de ing electrónica y quiero empezar a meterme un poco en electrónica por mi cuenta, hacer algo que un poco mas tangible. Esto porque en la facultad estoy todavía en el ciclo básico y hasta ahora solo he hecho materias de ciencias básicas (cálculos, algebras, físicas, química, etc.). Estoy siguiendo los tutoriales de arduino de Paul Mc Worther y este va a ser mi primer proyecto personal, algo sencillo para tratar de integrar conceptos antes de continuar. 

El objetivo es construir un sistema en el que un joystick controle la orientación de un servomotor que lleva montado un sensor ultrasónico.

Cuando el sensor detecte un objeto a una distancia determinada, el sistema activará LEDs y un buzzer.

## Componentes

- Arduino UNO
- Joystick
- Servomotor
- Sensor ultrasónico HC-SR04
- LEDs
- Buzzer
- Resistencias
- Protoboard
